## Third-party content and local changes

The launcher can download Java runtimes, mod loaders, and modpacks and manage
instance content. Those projects and providers have their own terms, licenses,
and privacy practices. Installing or launching third-party code lets that code
run on your computer; review its source and permissions where available.

important data before making changes. Uninstallation and data-removal guidance
is in the [README](README.md#uninstall) and
